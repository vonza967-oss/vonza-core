# Vonza Core

Vonza Core is a new, independent, Jarvis-inspired personal AI assistant. This repository starts from scratch; do not import or modify older Vonza/Lovable projects.

## Product goal
A private, reliable assistant that can chat in Hungarian and English, remember explicitly approved facts, manage tasks, and eventually support natural low-latency voice interaction and approved actions.

## Initial development
The first milestone is a working, testable web MVP with sign-in, AI chat, an explicit opt-in memory manager, task CRUD, responsive UI and secure server-side model access. See `AGENTS.md` for project instructions.

**Important:** Never commit API keys, credentials, `.env` files or private conversation data. This repository is public.

_Status: project bootstrap. The app has not been implemented yet._
